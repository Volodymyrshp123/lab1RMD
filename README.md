# FirstMobileApp

Мобільний додаток на базі **React Native** та **Expo**, розроблений у рамках лабораторної роботи. Додаток містить три основні екрани: стрічку новин, фотогалерею та форму реєстрації.

## Основні функції
1.  **Головна (Новини):** Список актуальних новин з можливістю перегляду детальної інформації у модальному вікні.
2.  **Фотогалерея:** Перегляд зображень у вигляді сітки (2 колонки) з функцією відкриття фото на весь екран.
3.  **Профіль (Реєстрація):** Форма реєстрації користувача з валідацією полів (email, пароль, прізвище, ім'я).

## Інструкція із запуску

### 1. Попередні вимоги
- Встановлений **Node.js** (LTS версія).
- Встановлений пакетний менеджер **npm** або **yarn**.
- (Опціонально) Застосунок **Expo Go** на вашому смартфоні (iOS/Android).

### 2. Встановлення залежностей
У терміналі в корені проєкту виконайте:
```bash
npm install
```

### 3. Запуск проєкту
Запустіть сервер розробки Expo:
```bash
npm start
```
Після цього відкриється вікно в браузері або з'явиться QR-код у терміналі.

## Способи запуску та тестування

### 1. Через Expo Go (на фізичному пристрої)
- **Призначення:** Найшвидший спосіб побачити додаток на реальному залізі без встановлення важких SDK.
- **Особливості:** Потрібно відсканувати QR-код через камеру (iOS) або додаток Expo Go (Android). Пристрій і комп'ютер мають бути в одній мережі Wi-Fi.
- **Відмінності:** Максимально наближено до реального використання користувачем, але обмежено можливостями клієнта Expo Go (не всі нативні модулі можуть працювати без власної збірки).

### 2. Емулятори та Симулятори (Android Studio / Xcode)
- **Призначення:** Тестування на різних версіях ОС та розмірах екранів без наявності фізичних пристроїв.
- **Особливості:** Вимагає встановлення **Android Studio** (для Android) або **Xcode** (для iOS, тільки на macOS).
- **Відмінності:** Дозволяє налагоджувати додаток у контрольованому середовищі. Працює швидше за Wi-Fi з'єднання, оскільки використовує локальний міст.

### 3. Веб-версія (Expo Web)
- **Призначення:** Швидка перевірка інтерфейсу та логіки в браузері.
- **Особливості:** Запускається командою `npm run web`.
- **Відмінності:** Найзручніший спосіб для верстки, проте деякі специфічні мобільні функції (наприклад, вібрація або робота з камерою) можуть працювати інакше або не працювати зовсім.
